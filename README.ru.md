# SharpFrame: резкие фото из видео

[English](README.md)

Выбираете момент в видео — получаете лучшее фото, какое позволяет запись. Это не скриншот: из
кадров в пределах ±0.12 с берётся самый резкий, а соседние, совмещённые с ним, убирают шум
и блоки сжатия там, где с ним совпадают.

![кадр примера, отмечены места кропов](docs/frame.jpg)

## Что получается

Быстрый пролёт на 1:23.6 ролика 4K 50 к/с, кропы 200 %. **Слева:** кадр в этот момент, как
его показывает плеер. **В центре:** SharpFrame. **Справа:** SharpFrame, `soft` (мягко).

![листья в желобе](docs/crop_leaves.jpg)

Листья в желобе крыши. Кадр в момент — промежуточный, сильно сжатый: листья размыты в блоки.
Через три кадра есть чёткий, его SharpFrame и берёт (у кадра в момент 87 % его резкости).

![обшивка и рама окна](docs/crop_window.jpg)

Окно: у кадра как есть обшивка — мутные пятна; в центре видна её текстура и чёткий край
рамы. `soft` смелее усредняет соседние кадры: картинка глаже и «ламповее», мелкой текстуры меньше.

![человек на траве](docs/crop_person.jpg)

Не везде выигрыш: за эти три кадра человек сдвинулся и в выбранном кадре чуть смазан, зато
трава вокруг чище. Самый резкий кадр выбирается по картинке в целом.

## Движение

Длинная выдержка у выбранного момента: всё, что движется в кадре, тянется шлейфом вдоль
своего пути, а то, что стоит в кадре на месте, остаётся резким. По умолчанию выдержка
заканчивается в момент, и шлейфы тянутся за движущимся; её можно поставить и вокруг момента
(шлейфы в обе стороны), и после него. При
полёте вперёд это точка, куда летит камера, и всё разлетается от неё лучами; при облёте
человека — сам человек.

![фото и тот же момент с движением и резкостью по ногам](docs/motion.jpg)

Облёт человека, 4K. **Слева:** фото в этот момент. **Справа:** движение 1/8 с до и после,
щелчок по ногам (кольцо): кадры ведутся за этим местом, человек остаётся резким, земля
закручивается вокруг.

Это ещё один этап поверх самого фото: опорный кадр и слияние не меняются. ~10 настоящих кадров
за выдержку стабилизируются (убирается тряска или они ведутся за точкой щелчка), каждый
смазывается вдоль своего движения на своём кусочке выдержки с шагом ≤ 1.5 пкс, кусочки
складываются. Настоящие кадры, а не одно фото, размазанное: то, что на фото закрыто
человеком, видно на других кадрах, поэтому его цвет не растекается в шлейфы вокруг. Где
ничего не движется, остаётся полное 4K-фото, граница идёт по краям самой картинки (фильтр,
направляемый цветом). Это ещё 20–25 с на фото 4K при 1/8 с; очень длинные выдержки быстрого
полёта считаются дольше и показывают «призраки» кадров, из которых собраны.


**Страница в браузере.** Двойной щелчок по `SharpFrame.bat` (или `python web.py`).
Перетащите видео на страницу, найдите момент в плеере (<kbd>,</kbd> <kbd>.</kbd> — на кадр
назад и вперёд), нажмите **Сделать фото**. Фото появится ниже с кнопкой **Сохранить**;
зажмите **Кадр как есть**, чтобы сравнить. **Мягко** включает мягкий вариант, **Движение** —
длинную выдержку (ползунок: от 1/60 до 1 с; до момента, до и после или после); на фото с движением щёлкните место, которое
должно остаться резким. Много моментов: на каждом **Добавить в список** (<kbd>+</kbd>), потом
**Сделать все**. Страницу
отдаёт локальный сервер, только на 127.0.0.1; видео копируется во временную папку, пока вы
ищете момент, и удаляется при выходе.

**Командная строка.**

```bat
SharpFrame.bat clip.mp4 0:12 0:47.5 1:03.2
SharpFrame.bat my_job.json
python sharpframe.py clip.mp4 83.6 --soft --save-single-frame
python sharpframe.py clip.mp4 83.6 --motion-seconds 0.125 --motion-focus 0.65,0.6
```

Фото ложатся в `<имя видео>_stills` рядом с видео, как `<имя видео>_<время>.jpg`.

**Настройки** берутся из [`sharpframe.json`](sharpframe.json) рядом со скриптом. Задание
добавляет видео и моменты, и свои `options` поверх; командная строка (через дефисы:
`--sharpen-amount 0`) главнее обоих:

```json
{
  "video_file": "F:/clips/clip.mp4",
  "times": ["0:12", "0:47.5", "1:03.2", "81.4"],
  "options": {"soft": true}
}
```

| ключ | что значит |
|---|---|
| `video_file` | видео; полный путь или относительно JSON |
| `times` | `"0:12"`, `"1:03.5"`, `"0:01:03.5"` или секунды (`81.4`) |
| `output_folder` | куда класть фото; `""` = `<имя видео>_stills` рядом с видео |
| `soft` | смело усреднять соседние кадры: глаже, «ламповее», мелких деталей меньше |
| `motion_seconds` | длинная выдержка в столько секунд, заканчивающаяся в момент; `0` = выкл. |
| `motion_when` | выдержка `"before"` — до момента (по умолчанию), `"around"` — до и после, `"after"` — после |
| `motion_focus` | `"x,y"` в долях кадра (`"0.5,0.5"` = центр) — что держать резким при `motion_seconds`; `""` = то, что стоит в кадре |
| `search_window_seconds` | сколько секунд по обе стороны от момента просматривать (0.12) |
| `max_frames_to_merge` | сколько кадров сливать самое большее, включая самый резкий (9) |
| `min_relative_sharpness` | кадры, у которых резкость меньше этой доли от самого резкого, не берутся (0.75) |
| `merge_tolerance` | множитель порога: больше — сильнее усреднение, меньше — ближе к самому резкому кадру (1) |
| `sharpen_amount`, `sharpen_radius_px` | повышение резкости (unsharp mask); `0` = выкл. (0.6, 1 пкс) |
| `lut_file` | цветовой LUT `.cube` при декодировании, например лог-профиль в Rec.709; `""` = нет |
| `save_single_frame` | ещё и самый резкий кадр отдельно (`<имя>_single_frame`) — видно, что дало слияние |
| `passthrough` | для тестов: кадр в момент как он декодирован (с LUT), без всякой обработки (`<имя>_passthrough`) |

## Как это работает

Для каждого момента:

1. кадры в пределах ±0.12 с декодируются в полной разрядности (10 бит в 16-битный RGB, цвет
   4:2:0 восстанавливается в своей настоящей позиции);
2. самый резкий становится опорным, так что смазанный или сильно сжатый кадр ровно в этот
   момент вам не достанется; кадру с края окна нужно быть резче примерно на 18 %, чтобы
   выиграть, — момент всё-таки выбрали вы. На обычном видео это бóльшая часть выигрыша: кадр
   в произвольный момент часто промежуточный, мягче и с блоками, а ключевой кадр в паре
   кадров от него — чёткий;
3. остальные резкие кадры совмещаются с ним оптическим потоком (DIS);
4. они подмешиваются попиксельно только там, где показывают то же самое: где локальная
   энергия разницы с опорным (размытый квадрат — мелкая текстура, сдвинутая на полпикселя,
   его не обнулит) не больше 3 уровней шума, а уровень шума берётся по лучше всего
   совмещённой десятой части кадра. Так небо, стена, крыша теряют шум, а листва на ветру,
   движущиеся люди и ошибки потока остаются пикселями опорного кадра. `soft` вместо этого
   сравнивает размытую разницу со знаком с 2.5 её медианы: мелкая текстура сходит за
   «одинаковое» и усредняется — отсюда мягкость;
5. повышение резкости, JPEG с качеством 96.

**Проверка.** В каждый кадр примера добавлен свой шум (σ 3 % диапазона), результат сравнивается
с чистым опорным кадром: один самый резкий кадр — 33.9 дБ, SharpFrame — 36.3–36.5 дБ, `soft` —
32.3 дБ. Без добавленного шума SharpFrame остаётся в 58 дБ от исходного кадра: текстуру не
мажет. На чистом дневном 4K слияние добавляет немного; чем темнее и шумнее запись, тем больше.

Режим увеличения (upscale) проверили и убрали: усреднение соседних кадров на вдвое более
частую сетку не обогнало простую бикубику одного самого резкого кадра.

Скорость: 12-20 с на фото для 4K (12-ядерный Xeon), в основном декодирование и оптический поток.

## Установка

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

`av` (PyAV: декодер FFmpeg внутри пакета, ffmpeg ставить не надо), `opencv-python-headless`,
`numpy`. Python 3.11.

## Для других

Готовый архив — на странице [Releases](https://github.com/parhipov/SharpFrame/releases):
распаковать куда угодно, запустить `SharpFrame.bat`, ничего не устанавливать (Windows 10/11,
64 бит).

Его собирает и выкладывает тег версии (`.github/workflows/release.yml`):
`git tag -a v1.1 -m "что изменилось" && git push origin v1.1`.

Вручную `build_zip.ps1` собирает `dist\SharpFrame.zip` (~80 МБ): встраиваемый Python с
пакетами из `.venv`, скрипты, страница и `README.txt`.

```bat
powershell -ExecutionPolicy Bypass -File build_zip.ps1
```
